Privacy Policy

OLERA Memory Backup · Ultimo aggiornamento: 9 novembre 2026

1. Titolare e contatti

OLERA Memory Backup è un'applicazione a uso personale, gestita dal titolare dell'account Google che ne autorizza il funzionamento. Per domande, richieste di accesso o cancellazione dei dati e revoca dell'utilizzo dell'app, è disponibile il contatto: samau8175@gmail.com.

2. Finalità del servizio

L'app serve esclusivamente a eseguire backup, consultare e verificare copie versionate della memoria operativa e della documentazione tecnica del progetto OLERA su Google Drive. Non è progettata per raccogliere informazioni cliniche identificative o fornire servizi sanitari.

3. Dati interessati

Quando viene autorizzata, l'app può trattare i file tecnici selezionati per il backup, i relativi nomi, percorsi, identificativi di versione, impronte di integrità, timestamp e log tecnici delle operazioni. Per accedere a Google Drive sono utilizzati token OAuth forniti da Google. Non richiede né conserva la password dell'account Google.

4. Permessi Google e limiti operativi

L'app usa l'API di Google Drive attraverso rclone. Il permesso OAuth richiesto può consentire tecnicamente l'accesso a un insieme di file più ampio rispetto alla singola cartella usata dall'applicazione. La configurazione prevista per OLERA Memory Backup limita le operazioni ordinarie ai file di memoria nella cartella Progetto Olera / OLERA_MEMORY. Tale limitazione è applicativa: non deve essere interpretata come una restrizione del permesso OAuth imposta da Google alla singola cartella.

5. Uso e comunicazione dei dati

I dati autorizzati vengono utilizzati per trasferimento, verifica, conservazione e consultazione delle copie di backup. Non sono venduti, non vengono utilizzati per pubblicità né per profilazione e non vengono condivisi con terzi per finalità commerciali. Google fornisce l'infrastruttura Drive attraverso cui vengono archiviati i file. Il sito informativo è ospitato su GitHub Pages, che può trattare dati tecnici di accesso secondo le proprie condizioni.

6. Conservazione e sicurezza

I backup e le relative versioni restano nell'account Google Drive autorizzato fino alla cancellazione da parte del titolare. I file sorgente e gli eventuali log tecnici possono restare sui sistemi controllati dal titolare secondo le configurazioni operative adottate. Le credenziali OAuth sono mantenute nella configurazione locale del software di sincronizzazione sul server autorizzato; non sono pubblicate su questo sito o nel repository GitHub Pages. L'accesso e la protezione dei sistemi dipendono dalle misure tecniche configurate sui rispettivi account e dispositivi.

7. Revoca, accesso e cancellazione

Il titolare può revocare l'accesso all'app dalle connessioni di terze parti dell'Account Google. La revoca impedisce nuovi accessi tramite il relativo consenso, ma non cancella automaticamente i backup già presenti su Drive o le copie locali: questi file vanno eliminati separatamente. Per richieste relative ai dati gestiti dall'app scrivere a samau8175@gmail.com.

8. Dati raccolti da questa pagina web

Questa pagina informativa non include moduli di raccolta dati, analisi statistiche proprietarie, pubblicità o cookie installati direttamente dal sito. Il provider di hosting GitHub Pages può tuttavia raccogliere dati tecnici necessari all'erogazione e alla sicurezza del servizio, secondo la propria informativa sulla privacy.

9. Modifiche

Questa informativa può essere aggiornata in caso di variazioni alle funzionalità, ai permessi o ai processi di conservazione. La data dell'ultima revisione è riportata in alto.

L'utilizzo di OLERA Memory Backup è riservato al titolare e non costituisce un servizio aperto al pubblico. Questa pagina descrive l'impiego previsto dell'applicazione, non autorizza la divulgazione di documentazione interna di OLERA.
